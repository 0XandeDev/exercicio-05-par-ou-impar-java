# Exercício 05 - Par ou Ímpar em Java

## Sobre o projeto
Programa desenvolvido em Java que solicita ao usuário um número inteiro e verifica se ele é par ou ímpar.

## Funcionalidades
- Solicita um número inteiro ao usuário.
- Verifica se o número é divisível por 2.
- Exibe uma mensagem informando se o número é par ou ímpar.

## Conceitos praticados
- Entrada de dados com Scanner.
- Declaração e utilização de variáveis.
- Estruturas condicionais (if e else).
- Operador módulo (%).
- Operadores relacionais.
- Lógica de programação.

## Tecnologias utilizadas
- Java
- IntelliJ IDEA

## Objetivo
Praticar estruturas condicionais e operadores aritméticos,
desenvolvendo o raciocínio lógico por meio da linguagem Java.
